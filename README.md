# 校園最短路徑導航

大一程式設計期末專題。在校園地圖上選起點和終點，程式用 **Dijkstra 演算法** 找出最短的走路路線，畫在地圖上，並列出每一段要走幾公尺、在哪裡轉彎、大約要走幾分鐘。

## 功能

- 輸入起點、終點時會自動推薦地點（可以打代號，例如 `j`，或部分名稱，例如「圖書」、「學生 停車」）
- 也可以直接點地圖：第一下是起點、第二下是終點
- 可以加一個途經點（可不填），例如「宿舍 → 7-11 → 教室」
- 找到的路線用紅線沿著道路畫出來，起點綠色、終點紅色
- 右邊列出每一站、每段距離、方向和轉彎（直走／左轉／右轉／迴轉）
- 顯示總距離和預估步行時間（走路速度設定為每分鐘 70 公尺）
- 「交換起點和終點」按鈕，可以馬上查回程
- 螢幕比較小時（例如 1366 寬的筆電、投影機），地圖會自動縮小，右邊面板不會跑出螢幕
- 地圖資料檔不見或格式錯誤時，會跳出視窗用中文說明原因（例如「JSON 格式有錯：第 12 行」）

## 執行環境

- Python 3（只用內建功能：`tkinter`、`json`、`heapq`、`math`、`unittest`，不用安裝任何套件）
- 字型使用 Windows 內建的「微軟正黑體」，在其他系統上中文字型可能會不一樣

## 執行方式

在 `campus_nav` 資料夾裡執行：

```
python main.py
```

## 執行測試

```
python -m unittest discover -s tests
```

## 地圖資料格式

`data/map_data.json` 裡有 74 個點、86 條道路。點分成四種：

| type | 意思 | 數量 |
|------|------|------|
| `building` | 建築（教學大樓、宿舍） | 12 |
| `facility` | 設施（球場、停車場、湖） | 18 |
| `gate` | 出入口 | 2 |
| `junction` | 路口（不能選，只用來連接道路） | 42 |

格式範例（數字只是示範）：

```json
{
  "nodes": [{"id": "J", "name": "J 圖書館…", "type": "building", "x": 190, "y": 215, "lat": 22.90, "lng": 120.46}],
  "edges": [{"from": "A", "to": "J", "distance_m": 45, "path": [[190, 215], [200, 230]]}]
}
```

- `x`、`y`、`path` 是地圖上的像素座標，只用來畫圖和判斷方向
- `distance_m` 是道路的實際距離（公尺），Dijkstra 用它當權重
- `lat`、`lng` 是地點的經緯度，主程式不用，只給 `tests/test_data.py` 檢查距離資料：
  沿著道路走的 `distance_m` 不可能比經緯度算出的直線距離還短；
  另外每條路的「公尺 ÷ 像素長度」都要在合理範圍（目前都在 0.69 ~ 0.91），超出就代表距離或折線打錯了
- 道路是雙向的；`path` 是沿著道路的折線，沒給的話就畫直線

## 演算法說明

1. 把地圖存成「鄰接表」：每個地點記錄它連到哪些地點、距離多少。
2. Dijkstra：用 `heapq`（優先佇列，每次都能拿出目前距離最短的那個）從起點開始往外擴展，每個地點第一次被拿出來時，就確定是最短距離。
3. 走到終點就提早結束，再沿著「每個地點是從哪裡走過來的」紀錄往回推，得到完整路線。
4. 走不到時回傳空路線和無限大距離；起點或終點不存在時直接報錯。
5. 有途經點時跑兩次 Dijkstra（起點 → 途經點、途經點 → 終點），再把兩段路線接起來、距離相加。
