校園最短路徑導航

實踐大學高雄校區：選起點和終點，找出最短的走路路線

建築 設施 出入口 最短路線 點圓點：第一下是起點，第二下是終點。手機可左右滑動地圖。

要去哪裡？

專題介紹

動機

高雄校區蓋在山坡上，建築分散，剛入學時常常不知道從宿舍到教室、從圖書館到體育館怎麼走最快。 所以我把校園做成一張「圖」，讓程式幫忙找出最短的走路路線。

怎麼把校園做成點和線

  • 點：建築、設施、出入口各是一個點，道路交叉的地方再放「路口」點，一共 74 個點。
  • 線：兩個點之間有路可以直接走到，就連一條線，一共 86 條；每條線記錄實際距離（公尺），也就是「權重」。
  • 道路是雙向的。資料存在 map_data.json，程式讀進來後整理成「鄰接表」：每個點連到哪些點、各多遠。

Dijkstra 演算法怎麼找最短路線

  1. 起點的距離設為 0，其他點都還不知道。
  2. 從還沒確定的點裡，挑出目前距離最短的那一個（用優先佇列 heapq，很快就能拿到最小的）。
  3. 這個點的距離就確定了。檢查它的每個鄰居：「經過它」走到鄰居如果比原本知道的短，就更新距離，並記下鄰居是從這裡走過來的。
  4. 重複第 2、3 步，直到終點確定；再從終點沿著記錄往回推，就是完整路線。

因為道路距離不會是負的，第一次被挑出來的點一定已經是最短距離。 網頁版的 JavaScript 照 Python 版一行一行改寫，74 × 74 組起點、終點的結果都和 Python 版一模一樣。 步行時間用每分鐘 70 公尺估算。
